    The format in one minute

    Sequences. The page is a list of sequences. Each one is ll literals, bytes stored as they are, then a match: copy ml bytes from offset bytes back. The last sequence has literals only.

    Two parts. All literals of the page come first, as they are or Huffman coded in 8 streams. Then the sequences as a bitstream, read highest bit first, as the literal streams.

    The token. One Huffman code says ll up to 14, ml up to 34 and the offset class together. One 11-bit table lookup gets all of it. Rare tokens are escaped and follow in 12 plain bits.

    Offset classes. 0: the repeat offset, 0 bits. 1, 2, 3: 4, 8 or 12 plain bits. 4, 5: 5 or 9 bits, times 8, for the many 8-byte things in memory.

    Length values. An ll of 15 or more, or an ml of 35 or more, adds a value after the offset: a short code and some plain bits.

    The exact rules are in docs/format.md; why they are this way in docs/seqlz.md.
